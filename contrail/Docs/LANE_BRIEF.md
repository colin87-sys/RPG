## Hard rules
1. **Tokens only.** Every colour comes from `src/style/tokens.ts` (derive with `mix/shade/withAlpha/tvec` from `src/style/color.ts`). No hex literals in your files. If you truly need a new base colour, append it to `palette` in `tokens.ts` inside a comment block `// --- <lane> additions ---` (never change existing values) and list it in your report.
2. **Seeded randomness only**: `Rng` from `src/core/rng.ts`. Never `Math.random()`.
3. **Shared lighting**: custom materials use `lightUniforms` + `GLSL_LIGHTING` (+ `GLSL_STD_VERTEX`) from `src/gen/common/lighting.ts` so one key light, one rim light, one ambient and one fog apply to everything. Do not fork that file; if it needs a change, describe it in your report.
4. **Zero external requests, zero assets**: no CDN, no fonts, no images, no audio files, no npm packages beyond what is installed. Everything is generated by code (canvas/DataTexture/geometry/shaders/WebAudio).
5. **Folder ownership**: write only inside your lane folder (given in your prompt), your lab boards `src/lab/boards/<your-prefix>*.ts`, your manifests, and `look/candidates/` files with your board names. Do NOT edit `src/main.ts`, `src/core/*`, `src/debug/*`, `src/game/*`, `vite.config.ts`, `package.json`, `index.html`, `lab/index.html`, `src/lab/main.ts`, `src/lab/context.ts`, other lanes' folders, or any `Docs/` file except appending one row per module to `Docs/INTEGRATION_QUEUE.md` and your own doc named in your prompt. Never run git. Kill only processes you started, by PID.
6. **Performance budgets** (per module; the game must hit 60 fps on a mid-range laptop GPU): hero craft <= 6k triangles; small enemy <= 900; strider <= 6k; boss <= 45k; one cloud/structure set <= 60k; whole frame <= 450k triangles and <= 250 draw calls at peak (instancing for repeats, merged geometry for statics). Generated textures <= 1024x1024 each, cached (build once, reuse). No per-frame allocations in update loops (pool/reuse vectors).
7. **API shape**: builders are pure functions of (params, seed) returning THREE objects; expose a small update(dt/time) where animation is needed. Export params types and at least 3 named parameter sets (variants A/B/C) that change palette use, lighting response, proportions or shading, not code paths.
8. **Manifest per module**: `src/gen/<lane>/<module>.entity.json` with `name`, `seed`, `params` (or variant names), `triangles`, `drawCalls`, `boundsMetres` [x,y,z], `tokensUsed` [...], `notes`.
9. **Max 3 attempts per module at the same stage**, then simplify and say so.
